# Your own boss model (optional)

The owner shows as a built-in figure. To use a rigged character instead, put a GLB here named `boss.glb` with animation clips named `walk`, `talk` and `sit` and a bone named `Hips`. `tools/bake-character.cjs` can merge separate clip files onto one rig.

`*.glb` files in this folder are gitignored, so a model you do not have the rights to share stays on your machine.
